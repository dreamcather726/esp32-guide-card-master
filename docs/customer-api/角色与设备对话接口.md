# Vanex S3 角色与设备对话接口

接口版本日期：2026-10-20；客户文档整理日期：2026-10-22。服务端接口调用不需要重新烧录固件。

## 地址与鉴权

基础地址：`https://robot.suji.work/xiaozhi/integration`

推荐由客户业务服务器调用，携带单独签发的接口密钥：

```http
X-API-Key: <customer-api-key.json 中完整的 apiKey>
Content-Type: application/json
```

`keyId` 只是密钥标识，不是认证凭证。也支持设备所属智控台账号的登录凭证 `Authorization: Bearer <登录Token>`，两种方式选一种，不要同时发送。MQTT 临时凭证不适用于本接口。

接口密钥限定在所属账号的数据范围内。原有仅画像权限的密钥保留原权限，新接口使用新签发的带对应权限密钥。长期密钥仅保存在客户业务服务器中，不放入网页、固件、公开仓库或群聊截图。

权限：`roles:read` 查询角色；`roles:write` 修改媒体；`device:role` 查询和设置设备角色；`history:read` 查询对话；`history:delete` 清空对话。交付密钥另包含原有 `profile` 权限。

所有接口先检查 HTTP 状态，再检查 JSON 的 `code`。`code=0` 表示操作成功，`data` 为结果；错误时读取 `msg`。写入成功与设备即时生效是两个状态，见下文 `runtimeStatus`。

沿用现有后台序列化约定，`total`、`deletedCount`、`bindingVersion` 等 64 位整数可能以十进制字符串返回，调用方需要按数值处理；ID 一律按字符串保存。

## 1. 按智能体查询全部角色

```http
GET /agents/{agentId}/roles
```

示例：`https://robot.suji.work/xiaozhi/integration/agents/ce9307e119034a219459334df1fff0e8/roles`

返回 `data` 为数组，每项包含：

```json
{
  "agentId": "智能体ID",
  "roleId": "角色ID",
  "roleName": "角色名称",
  "roleDefinition": "角色定义原文",
  "voiceId": "音色记录ID",
  "voiceName": "音色名称",
  "voiceCode": "语音服务使用的音色编码",
  "imageUrl": null,
  "videoUrl": null,
  "audioUrl": null,
  "sort": 1,
  "enabled": true
}
```

返回该智能体配置的全部角色及其对应音色，不是全部语音供应商的公共音色库。没有单独指定音色的角色，返回智能体默认音色。未设置媒体时返回 `null`。禁用角色也会返回，但 `enabled=false` 的角色不接受设备绑定。

## 2. 更新角色媒体

```http
PUT /agents/{agentId}/roles/{roleId}/media
```

```json
{
  "imageUrl": "https://example.com/role/avatar.png",
  "videoUrl": "https://example.com/role/avatar.mp4",
  "audioUrl": "https://example.com/role/audition.mp3"
}
```

三个字段分别是形象图片 URL、形象视频 URL、角色试听声音 URL。资源由客户提前上传到可访问的文件服务器，本接口保存地址，不上传或转码文件。仅接受 HTTP(S) 绝对地址，单个地址不超过 2048 字符，不带内嵌账号密码。

此 PUT 替换全部三个字段，遗漏字段、空字符串或 `null` 表示清空。返回更新后的完整角色。图片、视频及试听地址属于角色共享资料，修改后该角色的所有查询方均可看到；不会自动在设备屏幕播放视频，也不会替换 TTS 音色配置。

## 3. 设备标识

以下接口中的 `{deviceId}` 支持：

- 智控台设备 ID。
- MAC，例如 `7c:4f:ad:24:82:04`，也接受大写及短横线格式。
- 已登记设备映射的 IMEI，例如 `864479086531093`。
- 已登记设备映射的 cabGuid，例如 `864479086531093s3`。

IMEI/cabGuid 需要后台已登记其与设备 MAC 的对应关系，否则使用智控台设备 ID 或 MAC。设备必须属于接口密钥所属账号。

## 4. 绑定指定设备的角色

```http
PUT /devices/{deviceId}/role-binding
```

```json
{
  "agentId": "设备当前所属智能体ID",
  "roleId": "步骤1返回的角色ID"
}
```

示例返回：

```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "binding": {
      "deviceId": "智控台设备ID",
      "macAddress": "7c:4f:ad:24:82:04",
      "agentId": "智能体ID",
      "roleId": "角色ID",
      "bindingVersion": 1,
      "updatedAt": "由服务器返回"
    },
    "runtimeStatus": "applied"
  }
}
```

绑定持久化保存在服务端，只影响指定设备。设备必须已加入该智能体，本操作不负责把设备转移到其他智能体。它也不代替 `userGUID` 用户绑定流程。

`runtimeStatus` 含义：

| 值 | 含义 |
| --- | --- |
| `applied` | 已保存，在线语音连接已应用角色 |
| `saved_device_offline` | 已保存，设备当前没有语音连接，下次连接时加载 |
| `saved_pending_reconnect` | 已保存，设备忙或请求已被后续设置替代，下次重连加载最新绑定 |
| `saved_runtime_unavailable` | 已保存，即时通知服务暂不可用，下次重连加载；检查连接后可重新调用 |

重复设置同一角色不会重复递增绑定版本。设备正在播报时不强制中断，按返回状态安排重新连接。设备按键或显式角色指令仍可切换当前连接角色；查询绑定返回的是服务端保存的绑定，不是设备实时探测结果。

## 5. 查询设备绑定

```http
GET /devices/{deviceId}/role-binding
```

返回 `data` 为上述 `binding` 对象。尚未保存有效绑定时为 `null`。

## 6. 按设备查询对话记录

```http
GET /devices/{deviceId}/chat-history?page=1&limit=30
```

按时间倒序返回，默认每页 30 条，`limit` 为 1 至 100，`page` 从 1 开始。

```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "deviceId": "智控台设备ID",
    "macAddress": "7c:4f:ad:24:82:04",
    "page": 1,
    "limit": 30,
    "total": 2,
    "list": [
      {
        "id": "记录ID",
        "agentId": "智能体ID",
        "roleId": "角色ID",
        "userGUID": "用户ID",
        "sessionId": "连接会话ID",
        "usageSessionID": "用户使用会话ID",
        "turnId": "对话轮次ID",
        "chatType": 1,
        "content": "用户提问或助手回答",
        "audioId": null,
        "deliveryStatus": "由服务器返回",
        "createdAt": "由服务器返回"
      }
    ]
  }
}
```

`chatType=1` 为用户提问，`chatType=2` 为助手回答。旧记录部分上下文字段可能为 `null`。查询包含该设备已保存且当前账号有权读取的记录，不限于当前用户的这一次使用；不返回用户画像快照。`audioId` 仅为关联标识，不是音频下载网址。

## 7. 清空指定设备对话记录

```http
DELETE /devices/{deviceId}/chat-history?confirm=true
```

操作不可撤销，建议客户界面先二次确认。必须有 `history:delete` 权限且显式携带 `confirm=true`。

返回：

```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "deviceId": "智控台设备ID",
    "macAddress": "7c:4f:ad:24:82:04",
    "deletedCount": 12,
    "clearedAt": "由服务器返回",
    "runtimeStatus": "applied"
  }
}
```

删除该设备在当前账号权限内保存的对话及仅由这些记录独占引用的音频。不会删除用户画像、设备绑定或用户长期记忆，不影响其他设备的对话。

在线语音连接会以 `1012 / device_history_cleared` 断开，设备重新连接后建立新对话上下文；这可能中断正在进行的问答。若即时通知失败，记录已删除，但当前连接内存上下文需等重连或再次清空才能结束，以 `runtimeStatus` 为准。

服务端对清空前排队消息和删除记录的重试作丢弃处理，避免旧记录重新出现。设备重连后的新对话继续正常保存。此接口清空已保存对话和当前短期上下文，不等同于清除长期记忆。

## 调用示例

在客户业务服务器设置环境变量 `VANEX_API_KEY` 后：

```bash
curl --fail-with-body \
  'https://robot.suji.work/xiaozhi/integration/agents/ce9307e119034a219459334df1fff0e8/roles' \
  -H "X-API-Key: $VANEX_API_KEY"

curl --fail-with-body -X PUT \
  'https://robot.suji.work/xiaozhi/integration/devices/DEVICE_ID/role-binding' \
  -H "X-API-Key: $VANEX_API_KEY" -H 'Content-Type: application/json' \
  --data '{"agentId":"AGENT_ID","roleId":"ROLE_ID"}'
```

先查询角色，再用返回的真实 `agentId`、`roleId` 绑定设备，不使用示例占位符。
