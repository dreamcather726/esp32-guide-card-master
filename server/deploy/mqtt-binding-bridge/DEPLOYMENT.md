## 运行与回滚

```sh
docker logs --tail 80 vanex-mqtt-binding-bridge
docker inspect --format '{{.State.Health.Status}}' vanex-mqtt-binding-bridge
```

停止该容器即可暂停自动绑定，原有手工签发完整命令的流程仍保留。需要回滚 API 或
网页时使用 `backup/`，新增数据库表可以保留；不要直接覆盖整库而丢失新增对话记录。

客户提供的凭证接口目前是 HTTP，WSS 链路启用了证书验证。后续应由接口提供方启用
HTTPS，避免临时凭证在获取阶段经过明文传输。MQTT 3.1.1 的保留位只能可靠识别订阅时
回放的保留消息，发布端必须设置 retain=false。
